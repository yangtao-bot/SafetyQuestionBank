管理设置

获取 Token 方法：
1. 打开 GitHub Token 设置页
2. 点 "Generate new token" → 选 "Fine-grained"
3. Repository access 选 "Only select repositories" → 选 SafetyQuestionBank
4. Permissions → Repository permissions → Contents: Read and write
5. 生成后复制 token，粘贴到上方输入框

Token 仅存在你当前浏览器中（localStorage），不会出现在源码里。
